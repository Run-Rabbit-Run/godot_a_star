# Фазы сторон вместо очереди юнитов

**Статус:** в работе
**Начато:** 2026-11-03

## Цель

Бой идёт фазами фракций: сначала игрок ходит всеми своими юнитами в выбранном им порядке, затем все юниты противника. Порядок расстановки в редакторе перестаёт определять, кто ходит следующим. ИИ, headless-симуляция и графический бой используют одни и те же правила фаз.

## Не входит

- Инициатива и любые характеристики скорости.
- Выбор первой стороны в данных боя: первой всегда ходит фракция игрока.
- Отмена хода и показ намерений противника.

## Нужны решения владельца

- [x] Модель хода — фазы сторон (владелец, 2026-11-03).
- [x] Переключение внутри фазы — только по одному: юнит, начавший ход командой, заканчивает его действием или «Завершить ход», прежде чем ходит другой.
- [x] Эффекты начала хода (воздействие гекса, отсчёт перезарядки, штраф масла, возврат копья) — в начале фазы для всех юнитов стороны. Эффекты конца хода — сразу после действия или завершения хода юнита; юниты, не получившие их за фазу, получают их в конце фазы.
- [x] Призванный юнит действует со следующей фазы своей стороны.
- [x] Первой всегда ходит фракция игрока.

Рабочие допущения агента (сообщены владельцу, можно пересмотреть):

- Фаза принадлежит фракции (`BattleFaction`), а не стороне `BattleSideDefinition`. Раунд — фаза игрока и фаза противника; срок состояний гексов уменьшается при смене раунда, как раньше.
- Без начатого юнита активным считается первый готовый юнит фракции по порядку расстановки; команду может отдать любой готовый юнит фракции, и он становится начатым.
- Фаза заканчивается автоматически, когда у фракции не осталось готовых юнитов; `EndPhaseCommand` завершает ходы всех оставшихся сразу.
- Парализованный юнит в фазе не готов; паралич спадает в конце фазы вместе с другими эффектами конца.
- Юниты фракции под управлением ИИ ходят, когда становятся активными по порядку расстановки; игрок выбирает среди своих готовых юнитов.

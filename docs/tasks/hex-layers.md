# Гексы из двух слоёв: жидкость и энергия

**Статус:** в работе
**Начато:** 2026-11-03

## Цель

Двенадцать отдельных состояний гексов заменяются двумя независимыми слоями: жидкость (вода, масло, кислота, пар) и энергия (огонь, ток, плазма). Эффект гекса — сумма слоёв; реакций всего пять, и каждая объясняется одной фразой. Бой, ИИ, умения, редактор поля и отрисовка работают с двумя слоями; старые карты читаются с переводом.

## Не входит

- Предпросмотр реакций при прицеливании и справочная панель стихий — отдельный пункт «прогноз действия».
- Новые стихии и правка чисел статусов.
- Решение открытого вопроса о стоимости местности под состоянием: стоимость по-прежнему задаёт слой (масло — 2, иначе 1), очистка возвращает 1.

## Модель

| Слой | Значение | Воздействие | Прочее |
| --- | --- | --- | --- |
| Жидкость | `core:water` Вода | Влага ×2 | Проводит ток |
| | `core:oil` Масло | Тягучее масло ×2 | Проход стоит 2, горит |
| | `core:acid` Кислота | Кислота ×2, 1 кислотного урона | Проводит ток |
| | `core:steam` Пар | Влага ×1 | Укрытие −3 от выстрелов |
| Энергия | `core:fire` Огонь | Горение ×2, 1 огненного урона | |
| | `core:electricity` Ток | Наэлектризованность ×2, 1 электрического урона | |
| | `core:plasma` Плазма | Плазма ×2, 2 плазменного урона | Огонь + ток |

Правила:

1. Новая жидкость вытесняет прежнюю жидкость.
2. Огонь и ток на одном гексе дают плазму; плазма с огнём или током остаётся плазмой.
3. Огонь испаряет воду: вода и огонь исчезают, остаётся пар (с новым сроком 3).
4. Огонь бежит по маслу: соседние гексы с маслом получают огонь.
5. Ток бежит по воде и кислоте: соседние гексы с той же жидкостью получают ток.

- Воздействие на юнита: статусы жидкости, затем статусы энергии, затем урон жидкости и урон энергии отдельными событиями. Взаимодействия на юните делают существующие статусы (влага гасит горение, огонь взрывает масло).
- Повторное наложение того же значения слоя обновляет его срок до 3 без повторного воздействия.
- Попадание стихией (`DamageType`) накладывает свою стихию по тем же правилам, но только на гекс, где уже есть хотя бы один слой.
- Гекс с препятствием слоёв не получает.

Рабочие допущения агента (сообщить владельцу):

- Плазма с жидкостями не реагирует и не распространяется; влагу на юните снимает статус плазмы.
- Пар ток не проводит; огонь и ток поверх пара просто складываются с ним.
- Взрывы на уровне гекса (3 физического урона) убраны: огонь на масле взрывает только юнита на этом гексе через статусы «масло + горение».
- Перевод старых состояний: наэлектризованная вода → вода + ток; наэлектризованная кислота → кислота + ток; горящее масло → масло + огонь; кислотный пар → кислота + огонь; кипящая кислота → кислота; пар, плазма и базовые — в свой слой.
- Редактор поля рисует слои напрямую; реакции и распространение применяются при запуске боя, как сейчас нормализуется стартовая карта.
- Отрисовка: для пар со своей готовой текстурой используется она (вода + ток, кислота + ток, масло + огонь, кислота + огонь — текстура кипящей кислоты), остальные сочетания рисуются двумя слоями.

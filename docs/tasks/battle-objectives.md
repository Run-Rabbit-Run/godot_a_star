# Цели боя: продержаться, командир, защита, лимит раундов

**Статус:** в работе
**Начато:** 2026-11-03

## Цель

Кроме «уничтожить противника», бой может требовать продержаться N раундов или убить командира; любая цель может требовать сохранить отмеченных юнитов. Бой, не выигранный к концу лимита раундов (по умолчанию 99), проигран. Цель настраивается в редакторе поля.

## Не входит

- Зоны («удержать», «дойти»).
- Роли юнитов (толчок, лечение, щит).

## Затрагиваемые контракты

- `docs/architecture/BATTLE.md` «Завершение»
- `docs/architecture/BATTLE_PRESENTATION.md` «HUD», `docs/architecture/BATTLE_AI.md` «Тактический профиль»
- `docs/architecture/EDITOR.md`, `docs/tools/BATTLES.md`
- `docs/architecture/STATUS.md`, `docs/DECISIONS.md` (решение 2026-11-01 о бое без конца меняется)

## Нужны решения владельца

- [x] Цели «продержаться N раундов», «убить командира», «защитить юнита», без зон; панель цели в редакторе (владелец, 2026-11-03).
- [x] Лимит раундов как поражение, по умолчанию 99.

Рабочие допущения агента (сообщены владельцу):

- «Защитить юнита» — условие поверх любой цели: гибель любого защищаемого юнита — поражение.
- «Продержаться N»: победа, когда закончился раунд N, или раньше, если противник уничтожен. «Командир»: победа, когда погибли все командиры (их может быть несколько). Уничтожение противника всегда тоже победа.
- Поражение важнее победы при одновременном исходе (как сейчас). Лимит: поражение, когда раунд превысил лимит без победы; победа «продержаться» на том же рубеже проверяется раньше.
- Командиры — расстановки целевой фракции, защищаемые — расстановки защищаемой фракции; призванные юниты не отмечаются.

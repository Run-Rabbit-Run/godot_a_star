# Редактор навыков: только правка, описания, скорость

**Статус:** в работе
**Начато:** 2026-10-31

## Цель

Редактор навыков правит существующие активные и пассивные умения без лагов. Нельзя создать новое умение. У умения есть описание с переменными, которые подставляют итоговые значения эффектов. Описание видно в бою, в редакторе юнитов и в предпросмотре редактора навыков.

## Не входит

- Новые типы эффектов и новые правила боя.
- Правка призываемых юнитов, цели, флагов (ближняя атака, возврат, дальность атаки) и анимации умения: они только показываются.

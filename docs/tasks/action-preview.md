# Прогноз действия перед ходом

**Статус:** в работе
**Начато:** 2026-11-03

## Цель

Перед действием игрок видит его точный итог: ОЗ задетых юнитов, гибель, ответный удар, смену слоёв гексов, урон и статусы на маршруте. Наведение на врага показывает, куда он дойдёт и кого достанет в свою фазу.

## Не входит

- Намерения противника (ИИ заранее объявляет действия).
- Выбор безопасного пути при равной стоимости: маршрут только предупреждает.

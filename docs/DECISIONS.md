## Открытые вопросы

Эти правила нельзя придумывать попутно при работе над UI, контентом или адаптерами. Пока решение не принято, используется текущее простое поведение либо операция явно отклоняется. Если задача упирается в один из вопросов — остановиться и спросить владельца.

- стоимость местности под состоянием гекса: сейчас состояние заменяет стоимость, очистка возвращает 1, «болото 3 + вода» не складываются;
- стартовое воздействие гексов: все участники получают его при создании боя, первая фаза игрока не повторяет его;
- взрыв масла при поглощённом огне, плазма на базовых гексах, дальняя защита пара по дальности;
- подтверждение рабочих допущений модели слоёв из [HEX_AND_UNIT_STATES.md](architecture/HEX_AND_UNIT_STATES.md) «Рабочие допущения»;
- подтверждение рабочих допущений колб из [BATTLE_MAP.md](architecture/BATTLE_MAP.md) «Колбы»;
- одновременная гибель: сейчас приоритет у поражения защищаемой фракции, ничьей нет;
- поочерёдные реакции на урон по нескольким целям;
- новые статусы, стаки и сопротивления за пределами [HEX_AND_UNIT_STATES.md](architecture/HEX_AND_UNIT_STATES.md);
- дополнительные правила перемещения сверх принятого завершения хода действием;
- последствия удаления занятого гекса;
- многоклеточные существа;
- перенос травм и ресурсов между сценариями;
- точка сохранения и восстановление после поражения.

# A_star — оформление боя в направлении HotA

Дата: 2026-10-16. Реализация выбранного направления из [исследования](../concepts/2026-10-16-three-styles/README.md).

## Что изменено

- Три оригинальных фона A_star: парящее плато, корневой мир, грибные сады. Тёплая охра, цветные коричневые тени, подробные края и спокойнее центральная площадка. Размер каждого PNG — 1672×941. Исходные фоны сохранены.
- Общая тема HUD: тёмные бордово-коричневые панели, двойной золотистый кант, светлая слоновая кость для текста. Кнопки имеют состояния наведения, нажатия, недоступности и фокуса.
- Девять SVG-пиктограмм действий; для неизвестной авторской способности есть нейтральный знак. Назначенная автором иконка шаблона сохраняет приоритет.
- Более крупные карточки очереди, компоновка действий в два ряда для текущего набора, масштабирование стандартного HUD относительно 1920×1080.
- Единое оформление подсказок состояний гексов и юнитов, панели цели, журнала и настроек.
- Сдержаннее заливка доступных клеток и эффекты состояний; золотистое выделение активной клетки. Тени под фигурами плотнее; новые текстуры показываются без дополнительного осветляющего множителя.
- Редактор боя использует те же фоны и цветовые множители поля/фигур.

HotA используется как художественный ориентир; оригинальные ресурсы этой игры не включены. Это оформление существующей игры, без переноса её правил.

## Границы изменения

Правила, параметры юнитов, способности, ИИ, порядок ходов, состояния, урон, препятствия, JSON боёв и геометрия логической карты не изменены. Контуры по-прежнему вычисляются существующей логикой.

Перерисованы и подключены 61 растровый ассет: 21 персонаж и 21 погибший вариант, турель и её разрушенный вариант, 12 состояний гексов, пять препятствий. Сохранены холсты существующих изображений; опора у ног и atlas-регионы пересчитаны по новым силуэтам. Визуальные профили guide/reaper/sentry исправлены по соответствующим классам 82/96/90 px. Портреты пакета используют новые рисунки. Все состояния остаются отдельными элементами движка. Исходные отслеживаемые изображения доступны в Git; сгенерированные оригиналы сохранены отдельно.

Общая тема: `features/battle/ui/battle_visual_theme.gd`.
Палитра мира: `features/battle/view/battle_visual_palette.gd`.
Каталог фонов: `features/battle/view/battle_backdrops.gd`.
Контракты архитектуры не изменялись.

## Полный набор после переработки

- `all-units-battle-1080.png` / `all-units-battle-720.png`: все 21 персонаж, турель, 12 состояний и пять препятствий в штатном BattleScreen. Слева в каждом ряду повторён эталонный инженер. Стенд временный, авторские бои не перезаписаны. На стенде с 26 фигурами виден существующий предел ширины очереди HUD; её прокрутка не добавлялась.
- `all-units-editor-1080.png` / `all-units-editor-720.png`: тот же набор в редакторе.
- `corpses-1080.png`: 21 пара в штатной сцене смерти.
- `all-units-defeated-1080.png`: конечная фаза штатных анимаций смерти, включая турель; это визуальный стенд, без изменения состояния сессии.
- `asset-generation.json`: перечень файлов, измеренные границы, опоры, идентификаторы генераций и спецификации промптов. Использован встроенный image_gen.

Mipmaps включены для уменьшенных состояний, препятствий и новых пар; палитра урона и электрических эффектов согласована с материалами поля. Интерфейс инструментов разработки сохраняет свою рабочую тему; игровое поле внутри них использует общие ассеты. Ручной ввод мышью не проверен.

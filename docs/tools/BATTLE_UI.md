# Редактор UI боя

Открой `res://tools/battle_ui/battle_ui_editor.tscn` в Godot и нажми F6. Это инструмент разработки, исключённый из сборки игры. F5 запускает игру, F6 — открытую сцену инструмента.

## Работа с блоками

1. Выбери элемент мышью на холсте или в дереве слева. Чтобы двигать группу целиком, выбери `ActiveUnitPanel`, `ActionPanel` и т. п. в дереве.
2. Перемещай выбранный блок ЛКМ. Тяни за любую сторону или угол голубой рамки, чтобы изменить размер. Escape или потеря фокуса окна отменяет текущее перетаскивание.
3. Справа доступны координаты, размеры, текст, размер шрифта, цвета, прозрачность, рамка, изображение и видимость. Изменения формы фиксируются кнопкой «Применить свойства».
4. «Выбрать…» импортирует PNG/JPEG/WebP/SVG. Для кнопки это иконка, для портрета — изображение, для панели — фон. После выбора нажми «Применить свойства». «Убрать» убирает изображение, «Сбросить блок» возвращает исходное оформление целиком.
5. «Отмена» / «Повтор» или Ctrl+Z / Ctrl+Y отменяют применённые правки, включая одно полное перетаскивание. История ограничена 100 командами.

«Вписать» показывает весь холст 1920×1080. «1:1» показывает пиксели холста в масштабе 1:1 внутри логического viewport редактора. Средняя кнопка мыши перемещает вид. Изменение окна и масштаба не меняет документ. Минимальный размер блока ограничивается его содержимым: кнопка не становится меньше текста и отступов.

«Показать цель» и «Показать настройки» раскрывают эти панели только в предпросмотре. Скрытые элементы доступны через дерево. Для постоянной видимости используй свойство блока: «Управляет бой», «Всегда показывать», «Всегда скрывать».

## Тексты и данные боя

Поле текста по умолчанию содержит `{value}` — текущий текст, сформированный боем. Например, `Боец: {value}` сохраняет обновление имени. Обычный текст без `{value}` фиксирует надпись, в том числе на динамической метке. Сброс блока возвращает стандартное поведение.

Это оформление существующего HUD: игровые команды и данные остаются прежними. Статистика, очередь и доступность действий обновляются боем. Динамические карточки очереди не являются отдельными сохраняемыми элементами; в редакторе доступен их общий контейнер. Новые игровые кнопки и механики здесь не создаются.

## Сохранение и подключение

- «Сохранить» / Ctrl+S записывает текущий JSON. «Сохранить как…» создаёт другой вариант. «Открыть…» загружает вариант. Ошибка JSON оставляет открытый документ на месте.
- По умолчанию файлы находятся в `res://content/authored/ui` внутри проекта. Диалог позволяет выбрать другую папку.
- «Использовать в боях» сохраняет открытый вариант и назначает его следующим запускам боёв через `content/game_content.tres`. Назначаемый файл должен находиться внутри `content/`. Для нового документа откроется выбор имени файла; после успешного сохранения назначение выполнится автоматически. Уже запущенный бой не переключается.
- «Вернуть стандартный UI» очищает это назначение. Сохранённые варианты остаются на диске.
- У узла `BattleScreen` в Inspector есть `Ui Profile Path`. Укажи JSON, чтобы конкретная сцена использовала его независимо от общего назначения. Например: `res://content/authored/ui/compact.json`. Для принудительно стандартного оформления — `res://content/authored/ui/default.json`.
- «Пробный бой» запускает текущий стартовый бой из конфигурации проекта с копией несохранённого UI. Кнопка возврата возвращает к документу. Пробный бой не назначает профиль и не меняет документ.

В комплекте два примера: `content/authored/ui/default.json` и `compact.json` («Командная панель снизу»). Кнопка «Пример» открывает копию второго варианта; «Новый» — стандартный. Для собственного варианта используй «Сохранить как…».

Изображения извне копируются в `res://content/authored/ui/assets` с именем по хешу содержимого. При переносе проекта сохрани также эту папку; JSON сам изображения не содержит. Изображения проекта используют пути `res://`. Профиль экспорта `Windows Game` уже включает JSON и изображения проекта и исключает инструменты.

При открытии редактор загружает назначенный вариант либо стандартный UI. Свойство `Initial Profile Path` на корне внутренней сцены редактора позволяет явно указать стартовый документ.

## Прежняя проверка (2026-10-01)

В этой задаче проверены компиляция, запуск сцен и рендер стандартного/сохранённого UI в редакторе и бою. Автоматические тесты не добавлялись и не запускались. Интерактивный проход мышью, файловые диалоги и undo/redo требуют ручной проверки: computer-use не смог захватить окно Godot (таймаут).

Текущая граница проверки после переноса описана в [STATUS.md](../architecture/STATUS.md).

# Редактор навыков и эффектов

Откройте `tools/skills/skill_editor.tscn` и нажмите F6 либо нажмите «Навыки и эффекты» в редакторе поля.

Окно состоит из шапки с действиями, библиотеки слева, формы по центру, справки справа и строки состояния. Справа в строке состояния всегда виден итог проверки черновика на русском языке.

1. Выберите вкладку библиотеки: «Активные», «Пассивные» или «Эффекты» (шаблоны накладываемых эффектов).
2. Выберите определение слева либо нажмите «Новый» (`Ctrl+N`). Белые пункты — встроенные, бирюзовые — навыки проекта, пометка «[изменён]» — встроенные с сохранённым переопределением. «Копия» создаёт отдельное определение с новым ID.
3. В карточке «Основное» задайте название; там же видны ID и источник данных. В активном навыке карточка «Применение» задаёт цель, дальность, радиус, перезарядку, отображение и флаги. Поле «Дальность» неактивно, пока включена «Дальность базовой атаки».
4. Карточка «Эффекты» показывает порядок выполнения. «Добавить ▾» добавляет эффект нужного типа или копию шаблона, «Выше»/«Ниже» меняют порядок, «Удалить» недоступно для единственного эффекта. Выбранный эффект редактируется в карточке под списком.
5. Для урона задайте величину основной цели, величину остальных целей области и тип урона; при «Урон базовой атаки вместо чисел» поля величин неактивны. Для состояния юнита выберите состояние и уровни, для состояния гекса — состояние. Для призыва нужны цель «Пустой гекс», радиус 0 и единственный эффект. Повторный выбор того же типа эффекта не сбрасывает параметры.
6. Справка справа описывает выбранную цель и правила каждого эффекта: состояния юнита и гекса, их урон и распространение.
7. Нажмите «Сохранить» (`Ctrl+S`). Данные записываются в `content/authored/skills`. Изменение встроенного навыка создаёт переопределение, не перезаписывает исходный `.tres`.
8. В редакторе юнитов назначьте сохранённый навык. После изменений в другом окне нажмите «Обновить» в редакторе юнитов и «Файл ▾ → Перечитать библиотеку юнитов» в редакторе поля. При возврате из встроенного редактора поля библиотека обновляется автоматически. Новый бой использует сохранённые определения.

Пассивный навык задаёт бонус и тип урона базовой атаки, состояние/уровни за удар, иммунитет и ответный удар. Выбирайте только один пассивный навык, меняющий тип урона, для каждого юнита.

Категория эффектов создаёт шаблоны: добавляйте их кнопкой «Добавить из шаблона» в активный навык. Добавленная копия независима; изменение шаблона не меняет существующие навыки. Периодический урон, спад уровней и реакции встроенных состояний описаны в форме и используют правила игры.

«Отменить» и «Повторить» (`Ctrl+Z`, `Ctrl+Y` или `Ctrl+Shift+Z`) работают с данными текущего документа; набранное подряд название отменяется одним шагом. Смена категории, документа и закрытие спрашивают, следует ли отбросить несохранённые изменения. «Обновить» (`Ctrl+R`) перечитывает авторские файлы с диска.

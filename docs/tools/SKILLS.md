# Редактор навыков и эффектов

Откройте `tools/skills/skill_editor.tscn` и нажмите F6 либо нажмите «Навыки и эффекты» в редакторе поля.

1. Выберите категорию: активные навыки, пассивные навыки или накладываемые эффекты.
2. Выберите встроенное определение слева либо нажмите «Новый». «Создать копию» создаёт отдельный навык с новым ID.
3. Задайте название и параметры. В активном навыке выберите цель, дальность, радиус, перезарядку. Добавляйте эффекты и меняйте порядок кнопками «Выше» и «Ниже».
4. Для урона выберите величину основной цели, величину остальных целей области и один из шести типов урона. Для состояния юнита выберите состояние и количество уровней. Для состояния гекса выберите состояние. Для призыва необходимы пустой гекс, радиус 0 и единственный эффект.
5. Нажмите «Сохранить». Данные записываются в `content/authored/skills`; ошибки отображаются под формой. Изменение встроенного навыка создаёт переопределение, не перезаписывает исходный `.tres`.
6. В редакторе юнитов назначьте сохранённый навык. После изменений в другом окне нажмите «Обновить списки» в редакторе юнитов и «Обновить библиотеку юнитов» в редакторе поля. При возврате из встроенного редактора поля библиотека обновляется автоматически. Новый бой использует сохранённые определения.

Пассивный навык задаёт бонус и тип урона базовой атаки, состояние/уровни за удар, иммунитет и ответный удар. Выбирайте только один пассивный навык, меняющий тип урона, для каждого юнита.

Категория эффектов создаёт шаблоны: добавляйте их кнопкой «Добавить из шаблона» в активный навык. Добавленная копия независима; изменение шаблона не меняет существующие навыки. Периодический урон, спад уровней и реакции встроенных состояний описаны в форме и используют правила игры.

«Отменить» и «Повторить» работают с данными текущего документа. Смена категории, документа и закрытие спрашивают, следует ли отбросить несохранённые изменения.

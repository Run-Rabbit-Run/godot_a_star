# Редактор поля боя

Откройте `res://tools/battles/battle_editor.tscn` в Godot и нажмите F6.

Отдельный редактор юнитов: `res://tools/units/unit_editor.tscn` (F6) либо кнопка «Редактор юнитов» справа в разделе расстановки. Сохранённые пользовательские юниты попадают в палитру при возврате. После редактирования в другом процессе нажмите «Обновить библиотеку юнитов». Файлы и изображения доступны через кнопки папок в редакторе юнитов. Подробнее: `docs/tools/UNITS.md`.

- Состояния: выберите карточку снизу; ЛКМ наносит, ПКМ стирает. «Ластик состояния» стирает ЛКМ, кисть поддерживает протягивание.
- Юниты: выберите тип в правой палитре и сторону, затем расставляйте кликами по свободным клеткам. Для переноса выберите фигуру инструментом выбора, переключитесь на расстановку и нажмите на новый гекс. ПКМ в режиме выбора/расстановки удаляет фигуру.
- Форма: «Кисть: удалить гексы» убирает клетки из карты, «Кисть: добавить гексы» восстанавливает их в пределах 18×12. Занятую клетку сначала освободите.
- Фон, сетка, фигуры, undo/redo, сохранение и пробный бой доступны сверху. Возврат из пробного боя — сверху слева.
- «Открыть…», «Сохранить как…», экспорт и диагностика находятся ниже в прокручиваемой правой панели.

При запуске открывается текущий стартовый документ игры из `content/game_content.tres`. JSON хранит название, фон, состояния, форму поля и расстановку.

Вверху правой панели выберите поле в списке «Сохранённые поля боя» или нажмите «Новое поле». Новое поле — чистая сетка 18×12 без юнитов. Введите название и нажмите «Сохранить»: отдельный JSON появится в `content/authored/battles/` и в списке. Последующие сохранения обновляют этот файл; смена названия не создаёт копию. Название поддерживает отмену/повтор. При переключении или создании поля редактор спрашивает подтверждение, если есть несохранённые правки. «Обновить список» перечитывает файлы после изменений в другом процессе. Старые поля без названия показаны по имени файла.

Размер окна и полноэкранный режим меняются вверху правой панели без перезапуска. В полном экране используется размер монитора; выбранное разрешение окна применяется при выходе. Для встроенного запуска отключите Embed Game on Play в Godot. Колёсико больше не масштабирует поле; оно автоматически вписывается в рабочую область.

## Сохранение и запуск игры

«Сохранить как…» по умолчанию открывает `content/authored/battles/`. Полный путь файла виден в панели. «Сделать стартовым боем» сохраняет текущий документ, проверяет его с библиотекой проекта и назначает для F5. При новом документе сначала выбирается имя файла. Ошибка записи или обязательного контента не меняет назначение.

Сам документ — JSON, а не отдельная `.tscn`. Вся игра использует `features/game/game.tscn` и общий `BattleScreen`; карта и расстановка приходят из выбранного документа. Сохранять и назначать боевые документы рекомендуется внутри `content/`.

«Экспорт» создаёт вспомогательную копию в `content/authored/exports/<ID>/`. Она не является готовым модом и не назначает стартовый бой. Для переноса боя нужны также определения юнитов и изображения; весь набор уже лежит внутри проекта. Подробнее: [README.md](README.md).

Текущая граница проверки после переноса описана в [STATUS.md](../architecture/STATUS.md).


## Препятствия

Выберите «Кисть: препятствие», затем в правой панели задайте местность (холмы, река, лужи, деревья или камни), размер 1–4 гекса подряд и направление. Включите «Уничтожаемое препятствие» и задайте общие HP, если его можно разрушить. ЛКМ ставит целый объект; протягивание для этой кисти выключено. Можно выбрать начальный гекс инструментом выбора и нажать «Поставить / обновить препятствие».

Выбор любого гекса препятствия загружает общие свойства. Кнопка применения меняет тип, длину, направление, уничтожаемость и HP с сохранением начального гекса. ПКМ или «Удалить выбранное препятствие» удаляет объект целиком. Все действия поддерживают undo/redo и сохраняются вместе с полем.

На гексах препятствия нельзя размещать юнитов, ходить и наносить состояния. Объект не может выходить за существующую сетку, пересекать фигуры или другое препятствие. При размещении нанесённые состояния очищаются; undo восстанавливает их. Сначала удалите препятствие, если хотите убрать одну из его клеток карты.

В бою атакуйте любой гекс уничтожаемого препятствия в пределах дальности обычной атаки. HP общие для всей области; после разрушения все клетки открываются для движения и состояний. Урон способностей по площади учитывает один объект один раз за эффект. Наведение показывает свойства, общие HP или неуничтожаемость. Река и лужи здесь — непроходимые препятствия, а не состояния «вода».

# Редактор поля боя

Откройте `res://tools/battles/battle_editor.tscn` в Godot и нажмите F6.

Отдельный редактор юнитов: `res://tools/units/unit_editor.tscn` (F6) либо кнопка «Юниты…» в верхней строке. Сохранённые пользовательские юниты попадают в палитру при возврате. После редактирования в другом процессе выберите «Файл ▾ → Перечитать библиотеку юнитов» или «Перечитать» в карточке нового юнита. Подробнее: `docs/tools/UNITS.md`.

## Устройство окна

- **Верхняя строка**: меню «Файл ▾», выбор сохранённого поля, название, отметка «● Не сохранено», «Отменить»/«Повторить», «Юниты…» и «Навыки…» (встроенные редакторы), «Сохранить» и «▶ Пробный бой». Возврат из пробного боя — кнопкой сверху слева.
- **Полоса инструментов** над картой. У каждого инструмента своя клавиша: Выбор `V`, Юниты `U`, Состояния `B`, Ластик `E`, + Гексы `A`, − Гексы `D`, Поверхность `T`, Стоимость `C`, Препятствия `O`. Пока курсор стоит в текстовом поле, буквы вводятся в поле и инструмент не меняется.
- **Карта**. В правом верхнем углу — переключатели сетки и фигур, «−»/«+» (клавиши `−`, `=`) и «Вписать» (`F`). Средняя кнопка мыши — панорама. Масштаб и панорама меняют только вид, колёсико поле не масштабирует.
- **Правая панель** с вкладками:
  - «Инспектор» — подсказка активного инструмента и только нужные ему карточки: палитра состояний, тип/сторона нового юнита, свойства выбранного юнита, гекса или препятствия, список расставленных юнитов.
  - «Поле» — путь файла и действия с документом, фон, высота сетки, размер окна редактора.
  - «Проверка» — ошибки и предупреждения документа. Число ошибок видно в заголовке вкладки.
- **Строка состояния**: последнее сообщение (ошибки красные, предупреждения жёлтые), гекс под курсором (координаты, состояние, стоимость хода, препятствие, юнит), масштаб и итог проверки. Щелчок по итогу открывает «Проверку».

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` | Новое поле / открыть файл |
| `Ctrl+S` / `Ctrl+Shift+S` | Сохранить / сохранить как |
| `Ctrl+Z` / `Ctrl+Y` или `Ctrl+Shift+Z` | Отменить / повторить |
| `Delete` | Удалить выбранного юнита или препятствие |
| `Ctrl+D` | Дублировать выбранного юнита |
| `Esc` | Снять выбор |
| `F`, `−`, `=` | Вписать поле, уменьшить, увеличить |

## Работа с полем

- Юниты: нажмите `U`, выберите тип в списке, сторону и профиль ИИ, затем щёлкайте по свободным клеткам. Перенос — перетащите фигуру инструментом «Выбор»; на недопустимый гекс она не встанет, подсветка цели при этом красная. Юнита можно выбрать и в списке «Расставленные юниты». ПКМ в режимах выбора и расстановки удаляет фигуру.
- Состояния: нажмите `B` и выберите карточку в инспекторе; ЛКМ с протягиванием наносит, ПКМ стирает. «Ластик» (`E`) стирает левой кнопкой. Подсказка карточки описывает правила состояния.
- Форма: «− Гексы» удаляет клетки, «+ Гексы» восстанавливает их в пределах 18×12 с параметрами кисти. Занятую клетку сначала освободите. Для точечных правок в инспекторе есть поля q, r.
- Поверхность и стоимость хода наносятся кистью; значения задаются в карточке «Гекс и кисть местности». «Выбор» по гексу загружает его свойства, «Применить к выбранному гексу» сохраняет изменения.
- Фон выбирается на вкладке «Поле». Доступны также «Инопланетная арена · открытое поле» и «Инопланетная арена · кристаллы по краям». Подложка сохраняется вместе с полем и используется в пробном и обычном бою.

При запуске открывается текущий стартовый документ игры из `content/game_content.tres`. JSON хранит название, фон, состояния, форму поля и расстановку.

Выберите поле в списке «Поле» верхней строки или создайте новое через «Файл ▾ → Новое поле». Новое поле — чистая сетка 18×12 без юнитов. Введите название и нажмите «Сохранить»: отдельный JSON появится в `content/authored/battles/` и в списке. Если файл с таким именем уже принадлежит другому полю, редактор не перезаписывает его и предлагает выбрать имя. Последующие сохранения обновляют свой файл; смена названия не создаёт копию. Набранное подряд название отменяется одним шагом. При переключении или создании поля редактор спрашивает подтверждение, если есть несохранённые правки. «Обновить список полей» перечитывает файлы после изменений в другом процессе. Старые поля без названия показаны по имени файла.

Размер окна и полноэкранный режим меняются на вкладке «Поле» без перезапуска. В полном экране используется размер монитора; выбранное разрешение окна применяется при выходе. Для встроенного запуска отключите Embed Game on Play в Godot.

## Высота сетки

На вкладке «Поле» находится карточка «Сетка». Задайте смещение числом или нажимайте «Выше»/«Ниже» (шаг 10 px). Минус поднимает сетку, плюс опускает; значения считаются на холсте 1920×1080. Фон остаётся на месте, фигуры и эффекты следуют клеткам. Высота поля сохраняется обычным сохранением и поддерживает отмену/повтор.

«Сделать высотой по умолчанию» сразу сохраняет показанное значение для остальных полей без своей настройки, включая новые поля и следующие запуски редактора. «Использовать высоту по умолчанию» возвращает текущее поле к общему значению. Если у другого поля уже сохранена своя высота, она сохраняет приоритет. Общая настройка лежит в проекте (`content/authored/battle_grid_layout.cfg`) и также применяется в пробном и обычном бою.

## Сохранение и запуск игры

«Сохранить как…» по умолчанию открывает `content/authored/battles/`. Полный путь файла виден на вкладке «Поле». «Сделать стартовым боем» (меню «Файл», вкладки «Поле» и «Проверка») сохраняет текущий документ, проверяет его с библиотекой проекта и назначает для F5. При новом документе сначала выбирается имя файла. Ошибка записи или обязательного контента не меняет назначение.

Сам документ — JSON, а не отдельная `.tscn`. Вся игра использует `features/game/game.tscn` и общий `BattleScreen`; карта и расстановка приходят из выбранного документа. Сохранять и назначать боевые документы рекомендуется внутри `content/`.

«Экспорт копии документа» создаёт вспомогательную копию в `content/authored/exports/<ID>/`. Она не является готовым модом и не назначает стартовый бой. Для переноса боя нужны также определения юнитов и изображения; весь набор уже лежит внутри проекта. Подробнее: [README.md](README.md).

Текущая граница проверки описана в [STATUS.md](../architecture/STATUS.md).


## Препятствия

Нажмите `O` («Препятствия»), затем в инспекторе задайте местность (холмы, река, лужи, деревья или камни), размер 1–4 гекса подряд и направление. Включите «Уничтожаемое» и задайте общие HP, если препятствие можно разрушить. ЛКМ ставит целый объект; подсветка заранее показывает занимаемые гексы, протягивание для этой кисти выключено. Можно выбрать начальный гекс инструментом выбора и нажать «Поставить / обновить на выбранном гексе».

Выбор любого гекса препятствия загружает общие свойства. Кнопка применения меняет тип, длину, направление, уничтожаемость и HP с сохранением начального гекса. ПКМ, `Delete` или «Удалить выбранное препятствие» удаляют объект целиком. Все действия поддерживают undo/redo и сохраняются вместе с полем.

На гексах препятствия нельзя размещать юнитов, ходить и наносить состояния. Объект не может выходить за существующую сетку, пересекать фигуры или другое препятствие. При размещении нанесённые состояния очищаются; undo восстанавливает их. Сначала удалите препятствие, если хотите убрать одну из его клеток карты.

В бою атакуйте любой гекс уничтожаемого препятствия в пределах дальности обычной атаки. HP общие для всей области; после разрушения все клетки открываются для движения и состояний. Урон способностей по площади учитывает один объект один раз за эффект. Наведение показывает свойства, общие HP или неуничтожаемость. Река и лужи здесь — непроходимые препятствия, а не состояния «вода».

# Изображения персонажей

Выбранные варианты остальных героев: `sniper_dust_cloak.png` — снайпер «Пыльный плащ»; `alexandra_ochi.png` — Александра «Антенна»; `cartel_street_prince.png` — глава картеля «Уличный князь»; `space_cadet.png` — кадет «Гвардейская школа»; `barbara_boska.png` — Барбара «Полевой врач». Для каждой живой картинки добавлено парное тело. Точные задания генерации каждого варианта находятся в одноимённом JSON внутри `prompts/`, исходные пути и SHA-256 всех изображений — в `character_sources.json`.

`nika_iskra.png` — первый вариант Ники «Искры», «Уличная искра», с уточнённой боевой стойкой вправо. `saveliy_dopusk.png` — первый вариант Савелия «Допуск», «Корабельный механик». В `units/` находятся боевые фигуры, в `corpses/` — их парные лежащие версии. Профили масштаба и опоры хранятся в `content/authored/unit_visual_profiles.json`.

Источник: оригинальные изображения, созданные встроенным ImageGen по описаниям персонажей A_star. Для позы живых использованы собственные игровые ассеты `gt_spear_guard.png` и `gt_engineer.png`, для погибших — `gt_officer.png` и `gt_engineer.png` из `corpses/`. Входные PNG скопированы без изменения пикселей; при импорте включены mipmaps. Точные задания находятся в `prompts/nika_iskra.txt`, `prompts/saveliy_dopusk.txt` и `prompts/nika_saveliy_corpses.txt`.

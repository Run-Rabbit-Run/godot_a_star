# Парящее плато

Демонстрационный бой по образцу `minimal-ui/04-type-only-1920x1080.png` из Obsidian-папки `Визуал/Экраны боя — точная сетка 18x12`.

- Вход: `plateau:battle`, зависимость `core` 1.0.0.
- Карта: 216 явных осевых клеток, соответствующих 18 столбцам и 12 смещённым строкам.
- Расстановка и порядок 14 участников соответствуют образцу. Начало — первый раунд, полное здоровье. Повреждённое здоровье и третий раунд из иллюстрации не подделываются в HUD.
- Победа: уничтожить противника. HP и образы соответствуют типам фигур; урон, дальности и движение — предварительные параметры демонстрации, не утверждённый баланс.
- Действия используют существующие правила: движение, основная атака, граната из `core`, завершение хода. «Защита» — подпись завершения хода без нового баффа. «Поддержка» отсутствует, поскольку соответствующей механики пока нет.

`features/battle/art/plateau.png` скопирован из `assets/plateau.png`. Фигуры и портреты в `features/battle/art/plateau_units/` извлечены из `assets/units-source.png` с координатами и алгоритмом удаления связного фона из предоставленного `battle.js`. Новые рисунки не генерировались.

Повторный импорт атласа из корня проекта:

```powershell
& Z:/Godot/Godot_v4.7-stable_win64_console.exe --headless --path . --script tools/import_plateau_atlas.gd -- 'ПОЛНЫЙ ПУТЬ К assets/units-source.png'
```

Размеры фигур и опорные точки хранятся в presentation-ресурсах; отдельные портреты не меняют логические определения юнитов.

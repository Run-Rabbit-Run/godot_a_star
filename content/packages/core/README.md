# Изображения пакета core

## Турель

- `turret.png` — 384 × 384 RGBA, производная от `electric_turret.png` (тот же холст, силуэт и alpha). Перекрашена скриптом на `Image` Godot 4.7 попиксельно в HSV.
- Энергетические пиксели (тон 0,44–0,72, насыщенность ≥ 0,16) и белые сердцевины молний (насыщенность < 0,16, яркость > 0,72) внутри стекла ствола `Rect2i(205, 110, 170, 75)` и боковой колбы `Rect2i(40, 105, 42, 75)` стали оружейной сталью: тон 0,08, насыщенность 0,10, яркость `0,20 + 0,46 · v`.
- Линза в круге радиусом 15 вокруг `(127, 143)` стала красной: тон 0, насыщенность `min(1; 1,05 · s)`, яркость `0,95 · v`.
- `turret_dead.png` — 1536 × 1024, производная от `electric_turret_dead.png` по тем же правилам энергетических пикселей без поправки на стекло. Сталью стали синие провода, слабые синие отсветы погасшей линзы в круге радиусом 52 вокруг `(694, 470)` — тёмно-красными. Это та же разрушенная поза, а не повёрнутый живой рисунок.
- Импорт с mipmaps. Presentation `turret_presentation.tres` повторяет геометрию электрической турели: класс «небольшое существо», `actor_height` 76, `actor_max_width` 82, та же опора и область тела.

## Шаттл Здоровья

- `health_shuttle.svg` — исходник, нарисован вручную векторами (контуры, градиенты), без генератора изображений и без внешних образцов.
- `health_shuttle.png` — 384 × 384 RGBA, отрисован из SVG средствами Godot 4.7: `Image.load_svg_from_string(svg, 1.0)` и `save_png()`. Видимая фигура: x 82–301, y 14–371 (alpha-bounds).
- Импорт с mipmaps для чтения в игровом масштабе.
- Presentation `health_shuttle_presentation.tres`: класс «машина», `actor_height` 88, `actor_max_width` 90, опора `(0.5, 0.956)` — между опорами посадочных стоек; `arrives_from_sky` включает падение с неба.
- Погибшего рисунка нет: после гибели капсула уходит с поля вместе со своим гексом; переход падения показывает запасное тело из живого рисунка.

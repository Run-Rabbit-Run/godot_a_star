# Рисунки колб

Векторные рисунки десяти колб для поля боя и редактора: колба и большая колба с кислотой, водой, маслом и электричеством, колба под давлением и взрывоопасная колба.

- Источник: файлы созданы программно, без генеративных моделей изображений.
- Инструмент: `tools/art/generate_flask_art.py`; запуск из корня проекта `python tools/art/generate_flask_art.py` перезаписывает все SVG этой папки.
- Параметры: формы, палитры жидкостей (`LIQUIDS`, `EXPLOSIVE`, `GAS`) и детали заданы в генераторе. Холст 100×140 у колб, 140×150 у большой колбы, 110×150 у колбы под давлением.
- Импорт Godot: `svg/scale=2.0`, `mipmaps/generate=true` в `.import`; после правки импорта выполнить `--headless --editor --quit`.
- Размер на поле задаёт `ObstacleArt.WIDTHS`, опору — `ObstacleArt.ANCHORS`.

# Анимация передвижения

Три редактируемых ресурса Godot: `human_walk.tres`, `heavy_walk.tres`, `creature_walk.tres`.
Привязка к юниту: `UnitPresentationDefinition.movement_profile`.

- Human: Сорокин, Стрелок/ranger, Проводник/guide.
- Heavy: Бастион, Панцирь/carapace.
- Creature: Жнец/reaper, Спора/spore, Часовой/sentry.

Это процедурная cutout-походка поверх существующих PNG: лёгкий сдвиг нижней части рисунка,
подъём и покачивание корпуса. Здесь нет новых нарисованных кадров или отдельных ракурсов.
Шейдер `walk.gdshader` получает фазу от того же Tween, который перемещает актора.
Портреты, HUD и логика боя не меняются.

Для визуальной настройки откройте `res://features/battle/view/movement_preview.tscn` и нажмите F6.
Сцена показывает все восемь фигур на фоне поля; кнопки 0.5x/1x/2x/4x меняют скорость
прямо во время движения. Это галерея анимаций, а не симуляция боя.

Параметры ресурсов: `seconds_per_hex` (секунды на гекс при 1x), `lift` (пиксели),
`sway_degrees`, `lean_degrees`, `stride` (доля UV), `leg_start`, `leg_split`.
Ресурсы разделяются несколькими юнитами; для индивидуальной походки создайте копию профиля.

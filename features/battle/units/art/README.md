# Временное арт-направление боя

Этот набор предназначен для текущего вертикального среза и не фиксирует
окончательный лор.

## Рабочая гипотеза

- Союзники — человеческая экспедиционная группа с корабля «Фобос».
- Противники — автономные боевые машины, повреждённые жаром и пеплом.
- Люди читаются по холодным синим и циановым акцентам.
- Машины читаются по угольному металлу, светлой керамике и янтарному жару.

## Файлы

- phobos_guard.png — союзный боец ближнего боя.
- phobos_marksman.png — союзный стрелок.
- ash_machine_cleaver.png — вражеская машина ближнего боя.
- ash_machine_gunner.png — вражеская машина дальнего боя.

Исходники имеют размер 1254×1254 и прозрачный фон. Godot импортирует их
с ограничением 256 пикселей, а UnitActor вписывает изображение в 52 пикселя.

## Prompt-инварианты

- стилизованный hand-painted 2D;
- ракурс три четверти сверху для тактического поля;
- сильный силуэт, читаемый в малом размере;
- один персонаж целиком;
- прозрачный фон;
- без текста, рамки, окружения, логотипов и водяных знаков.
